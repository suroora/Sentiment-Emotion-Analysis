# Sentiment / Emotion Analysis

## Objective

Classify emotions in text using Naive Bayes and Support Vector Machine.

## Files

-   DL Assignment-4.ipynb -- Complete notebook
-   README.md -- Instructions

## Dataset

Save your dataset as `emotion_dataset.csv` with columns: - text - label

## Steps Implemented

1.  Text cleaning (lowercase, special character removal, stopwords)
2.  TF-IDF feature extraction
3.  Naive Bayes model
4.  SVM model
5.  Model comparison using Accuracy & F1-score

## How to Run

1.  Place `emotion_dataset.csv` in the same folder.
2.  Open the notebook.
3.  Run all cells.

## Libraries

-   pandas
-   nltk
-   scikit-learn

SVM generally provides better performance for emotion classification.
